Common Questions

Frequently Asked Questions

Everything you need to know about hardware requirements, air-gap security, and local intelligence.

Can I use CPU and GPU simultaneously like LM Studio?
Yes. Local Brain utilizes node-llama-cpp with a bundled Vulkan compute backend that natively supports hybrid offloading. You can allocate a set number of transformer layers to your GPU's VRAM (e.g., 12 layers on a 4GB card) while streaming the remaining layers through CPU AVX2 SIMD in system memory. Alternatively, if you run LM Studio locally, Local Brain integrates seamlessly via its http://localhost:1234/v1 endpoint.
What happens if my GPU runs out of VRAM?
Local Brain includes an automatic VRAM Safe Mode. If your GPU has limited free VRAM (or experiences a CUDA allocation error such as CUDA 108), Local Brain automatically catches the event and falls back to CPU AVX2 SIMD execution without crashing your application. Your summaries and vector queries will always succeed.
How do I delete or nuke the initial example data?
You can clean your library at any time by clicking the Nuke Example Data button located in the Library toolbar, or under Settings > Data Management. This wipes all sample documents, LanceDB vectors, and generated wikis from SQLite and local storage, leaving a clean, empty canvas ready for your private files.
Can I bring my own GGUF models into the Minimal Edition?
Absolutely. In the Minimal Edition, simply drop any compatible .gguf model (Llama 3, Gemma 2, Mistral, Qwen 2.5, Phi-3) into the models/llm/ directory. Local Brain automatically detects the model on startup and initializes the local C++ inference runtime.
Does Local Brain send telemetry or analytics to external servers?
Zero. When using the embedded Local SLM or a local LM Studio server, all document ingestion, optical chunking, LanceDB vector storage, and neural inference occur strictly in local memory. There are no telemetry pings, error reporting beacons, or analytics collectors built into the binary.
Can I export synthesized wikis and summaries to Obsidian?
Yes. Every document summary and AI-generated wiki page can be exported to standard CommonMark Markdown with YAML frontmatter tags. You can point the export target to an existing Obsidian vault or markdown folder.
