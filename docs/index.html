System Architecture

Engineered for Privacy & Performance

In-Process C++ SLM

Powered by node-llama-cpp v3, executing direct C++ memory-mapped inference without requiring Python, PyTorch, or background server daemons.

Hybrid LanceDB Retrieval

Combines dense vector cosine distance with inverted keyword weighting to synthesize answers with precise chunk citation references.

Immutable Versioning

Stores revision history snapshots in SQLite WAL mode. Easily restore, diff, or inspect past document revisions at any time.

Multi-Provider Router

Switch between the on-device Gemma 4 SLM, local LM Studio daemons, curated free OpenRouter models, and Google Gemini from the desktop titlebar.
